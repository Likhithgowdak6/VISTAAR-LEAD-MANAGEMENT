# Verifies and mints the bcrypt hashes the Node backend reads. Node uses bcryptjs; both emit

# The IANA timezone database. NOT optional and NOT merely a Windows convenience: python:3.11-slim
# carries no system tzdata either, so ZoneInfo("Asia/Kolkata") raises there too. Every analytics
# boundary is a LOCAL midnight in the studio timezone, so without this the dashboard either
# fails outright or - worse, if a fallback were ever added - silently reports UTC days and shifts
# every number by 5.5 hours.
